强调（粗体和斜体）
粗体：用两个 ** 或 __ 包裹文本。
斜体：用一个 * 或 _ 包裹文本。
粗斜体：用三个 *** 或 ___ 包裹文本。

列表
无序列表
使用 -、+ 或 * 作为列表标记。
- 项目一
- 项目二
  - 子项目一（通过两个空格或一个制表符缩进）
  - 子项目二
- 项目三

有序列表
使用数字加 . 来标记。

1. 第一项
2. 第二项
   1. 第二项的子项（同样需要缩进）
3. 第三项

代码
行内代码：用一个反引号 ` 包裹代码。

代码块：用三个反引号 ``` 包裹代码，并可以在开始的反引号后指定语言以实现语法高亮。

markdown
这是一个 `行内代码` 的例子。

```python
# 这是一个Python代码块
def hello_world():
    print("Hello, World!")
```

```javascript
// 这是一个JavaScript代码块
console.log("Hello, World!");
```

割线
使用三个或更多的 ***、--- 或 ___ 来创建一条水平分割线。

表格
使用竖线 | 和连字符 - 来创建表格。连字符用于分隔表头和单元格，冒号 : 用于指定对齐方式。

markdown
| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 单元格内容 | 单元格内容 | 单元格内容 |
| 第二行 | 数据 | 数据 |
