Spring Boot快速入门指南

一、Spring Boot简介与核心特性

什么是Spring Boot？

Spring Boot是基于Spring框架的"约定优于配置"理念开发的开源框架，旨在简化Spring应用程序的初始搭建和开发过程。

核心特性：

  1. 自动配置 - 根据类路径和配置自动配置Spring应用
  2. 起步依赖 - 提供预配置的依赖集合，简化构建配置
  3. 内嵌服务器 - 内置Tomcat、Jetty或Undertow服务器
  4. 生产就绪 - 提供健康检查、指标、外部配置等生产级功能
  5. 无代码生成 - 无需XML配置，通过Java注解和配置类配置

二、第一个Spring Boot应用程序

1. 环境准备

  • JDK 8或更高版本
  • Maven 3.3+ 或 Gradle 4.4+
  • IDE (推荐IntelliJ IDEA或VS Code)

2. 快速创建Spring Boot项目

方法一：使用Spring Initializr（推荐） 访问 https://start.spring.io/ 或使用IDE集成工具

方法二：手动创建Maven项目

<!-- pom.xml -->
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 
         http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>2.7.0</version>
        <relativePath/>
    </parent>
    
    <groupId>com.example</groupId>
    <artifactId>demo</artifactId>
    <version>0.0.1-SNAPSHOT</version>
    
    <properties>
        <java.version>11</java.version>
    </properties>
    
    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>
    </dependencies>
    
    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
</project>

3. 创建主应用程序类

// DemoApplication.java
package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@SpringBootApplication
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

@RestController
class HelloController {
    
    @GetMapping("/hello")
    public String hello() {
        return "Hello, Spring Boot!";
    }
}

4. 运行应用程序

# 方法一：使用Maven
mvn spring-boot:run

# 方法二：运行主类
# 直接运行DemoApplication类的main方法

5. 测试应用

访问 http://localhost:8080/hello 查看结果

三、自动配置原理初探

核心注解：@SpringBootApplication

@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@Documented
@Inherited
@SpringBootConfiguration
@EnableAutoConfiguration
@ComponentScan
public @interface SpringBootApplication {
    // ...
}

自动配置的工作原理：

  1. @EnableAutoConfiguration 启用自动配置
  2. META-INF/spring.factories 包含自动配置类列表
  3. 条件注解 决定是否应用配置
    • @ConditionalOnClass
    • @ConditionalOnMissingBean
    • @ConditionalOnProperty
    • @ConditionalOnWebApplication

示例：查看自动配置报告

# application.yml
debug: true  # 启用调试模式，查看自动配置报告

运行应用后，控制台会显示：

  • Positive matches: 已应用的自动配置
  • Negative matches: 未应用的自动配置
  • Exclusions: 排除的配置

四、起步依赖(Starter)详解

什么是起步依赖？

起步依赖是预配置的依赖描述符，简化了依赖管理。每个起步依赖都提供了一组相关的库。

常用起步依赖：

起步依赖功能描述
spring-boot-starter-webWeb应用开发
spring-boot-starter-data-jpaJPA和Hibernate
spring-boot-starter-security安全认证授权
spring-boot-starter-test测试支持
spring-boot-starter-actuator监控和管理
spring-boot-starter-thymeleafThymeleaf模板引擎

起步依赖的优点：

  1. 简化依赖管理 - 无需指定版本号
  2. 版本兼容性 - 所有依赖版本已测试兼容
  3. 功能模块化 - 按需引入功能模块

自定义起步依赖示例：

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>

创建自定义起步依赖：

  1. 创建Maven项目
  2. 添加必要的依赖
  3. 创建配置类
  4. 在META-INF/spring.factories中注册
// 自定义自动配置类
@Configuration
@ConditionalOnClass({MyService.class})
@EnableConfigurationProperties(MyProperties.class)
public class MyAutoConfiguration {
    
    @Bean
    @ConditionalOnMissingBean
    public MyService myService(MyProperties properties) {
        return new MyService(properties);
    }
}

// 在 resources/META-INF/spring.factories 中注册
// org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
// com.example.MyAutoConfiguration

六、快速启动检查清单

  1. ✅ 确保JDK版本符合要求
  2. ✅ 选择合适的构建工具（Maven/Gradle）
  3. ✅ 使用Spring Initializr或IDE创建项目
  4. ✅ 添加需要的起步依赖
  5. ✅ 创建主应用程序类（@SpringBootApplication注解）
  6. ✅ 配置application.properties/yml文件
  7. ✅ 编写业务代码（Controller/Service/Repository）
  8. ✅ 运行应用程序测试

学习建议

  1. 循序渐进：从简单的Web应用开始，逐步添加更多功能
  2. 理解原理：不要只停留在使用层面，要理解自动配置机制
  3. 阅读源码：查看spring-boot-autoconfigure模块源码
  4. 实践为主：多动手编写代码，尝试不同配置
  5. 关注日志：通过debug=true查看自动配置决策过程

通过这个快速入门，你已经掌握了Spring Boot的基本概念和核心特性，可以开始构建自己的Spring Boot应用了！
